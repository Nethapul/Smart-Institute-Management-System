Project Setup

Follow these steps to set up the project locally:

1. Prerequisites

Ensure you have Node.js installed on your machine. We recommend the latest LTS version.

2. Installation

Open your terminal in the project root directory and run the following command to install dependencies:

npm install
3. Development Server

Start the development server to view the app in your browser:

npm run dev
4. Build for Production

To generate a production-ready build, run:

npm run build

The build artifacts will be stored in the dist/ directory. You can upload the contents of this directory to your web server (e.g., public_html).
